# URAI V2 Knowledge Base

> Updated: May 2026. This file explains the current V2 base in plain language.

## Short Version

URAI production chat now searches V2 Qdrant collections. V2 is not a future
shadow base anymore. It is the main retrieval layer used by the chat pipeline.

V2 stores legal documents as text chunks plus 3072-dimensional vectors from
`gemini-embedding-001`. A user question is also embedded, and Qdrant finds
chunks that are semantically close. The backend then applies legal-specific
reranking so the answer is based on direct, current and authoritative sources.

## Why V2 Exists

Legal questions often need a very specific fragment inside a large code,
resolution or procedure. Searching only "similar documents" is not enough.

V2 improves this by combining:

- stronger embeddings;
- thematic Rada collections;
- source-specific collections for KMU, MOD, ZIR, court and wiki sources;
- keyword and title fallback;
- article-window protection for norms split across chunks;
- evidence subquestions for multi-part questions;
- metadata enrichment for status, dates and cancellation signals.

## Raw Text Storage

Scrapers save raw source files to:

```text
/root/laws_raw/{source}/{law_id}.txt
/root/laws_raw/{source}/{law_id}.meta.json
/root/laws_raw/scrape_status.json
```

Supported source keys:

| Source | Meaning | Main scraper |
| --- | --- | --- |
| `rada` | Laws, codes and Rada acts from zakon.rada.gov.ua | `scrape_all_v2.py` |
| `kmu` | Cabinet of Ministers acts | `scrape_all_v2.py` |
| `ccu` | Constitutional Court materials | `scrape_all_v2.py` / scanner |
| `supreme` | Supreme Court practice reviews/materials | `scrape_all_v2.py` / scanner |
| `wiki` | LegalAid Wiki explanatory articles | `scrape_all_v2.py` / scanner |
| `positions` | Supreme Court legal positions from LPD | `scrape_all_v2.py` / scanner |
| `mod` | Ministry of Defense documents from mod.gov.ua | `scrape_mod_v2.py` |
| `zir` | ZIR/DPS tax Q&A | `scrape_zir_v2.py` |

## What MOD Means

`mod` is the Ministry of Defense source. The `laws_mod_v2` collection contains
documents scraped from `mod.gov.ua`, mainly PDF-based orders, procedures,
methodical and reference materials. Its strongest practical area is military
administration: personnel, finance, property and defense-related procedures.

It is a useful official source for military/MOD details, but it does not replace
Rada laws or KMU resolutions when those are the direct governing acts.

## Reindex

`backend/reindex_v2.py` converts raw text into vectors:

1. Read `/root/laws_raw/{source}/{law_id}.txt`.
2. Split into chunks.
3. Embed chunks with `gemini-embedding-001`.
4. Delete old chunks only after embedding succeeds.
5. Upload new chunks and metadata to the correct V2 collection.

Chunk sizes currently used by `reindex_v2.py`:

| Source | Chunk size | Overlap |
| --- | ---: | ---: |
| `rada` | 3000 | 600 |
| `kmu` | 3000 | 600 |
| `ccu` | 3000 | 300 |
| `supreme` | 3000 | 300 |
| `wiki` | 2000 | 200 |
| `positions` | 2000 | 200 |
| `mod` | 3000 | 300 |
| `zir` | 2000 | 200 |

The larger Rada/KMU overlap matters because many norms contain a condition in
one paragraph and a sanction or consequence in the next.

## Metadata Enrichment

Rada/KMU metadata can be enriched from OpenData and text cancellation scans.
Important fields include:

- `rada_status`, `rada_status_name`;
- `rada_is_dead`, `rada_is_dead_by_status`, `rada_is_dead_by_link`,
  `rada_is_dead_by_text`;
- `rada_adopted_date`, `rada_last_edition`, `rada_dead_since`;
- `rada_replaced_by`, `rada_cancelled_by`, `rada_cancelled_by_text`;
- `rada_theme`, `rada_org`, `rada_doc_type`.

The chat pipeline filters expired/cancelled documents before final context when
metadata indicates they should not be used as current law.

## How Chat Uses V2

The chat does not search only one guessed collection. It uses:

- plan source gating from the user plan;
- semantic collection hints;
- AI query planner target collections;
- original and planned semantic searches;
- keyword and title searches;
- dynamic primary-act discovery;
- aspect/evidence coverage;
- deterministic answerability reranking;
- final context squeeze.

This is why V2 can answer both simple direct-norm questions and broader
multi-aspect questions.

## Admin Control

The main V2 controls are in:

- `/admin/v2` - scraper/reindex/data overview;
- `/admin/sync` - source summary;
- `/admin/meta` - metadata enrichment and Qdrant patching.

Do not run concurrent V2 reindex jobs. The backend guards this, but operators
should not bypass it.
